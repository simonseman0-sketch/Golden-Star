Golden Star V55 QuickBooks IIF export

1. Upload text-based packing PDF.
2. Match each SKU to exact QuickBooks item name (suggestions are from provided active Item List Excel).
3. Correct all quantities; PDF parser cannot guarantee reading quantities.
4. Enter selling prices from QuickBooks (not included in uploaded Excel).
5. Set invoice number (11 chars maximum), date, customer, A/R and income account.
6. Tick confirmation and download IIF.
7. TEST IN BACKUP COMPANY FILE FIRST. IIF import creates a real invoice.
8. Does not generate QuickBooks next invoice number automatically.
9. No product or order data is uploaded by this feature.
