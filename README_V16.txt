GOLDEN STAR WAREHOUSE ORDER DESK V16
Free browser-based automatic Arabic suggestions for unknown items.

Upload the CONTENTS of this folder to Netlify (or zip contents).
Unknown items receive automatic suggestions after Convert; you can also retry using the
Translate Arabic here button. First use downloads an
English→Arabic model to the browser from Hugging Face via Transformers.js,
which may be large and slow. No paid translator key or service needed.
The translator suggests standard Arabic, NOT guaranteed Iraqi dialect.
Staff must check and edit translations before approving them. Suggestions
do NOT automatically enter the shared dictionary.

The browser requires internet for the first download; subsequent loading
may use browser cache. If downloads fail, manual Arabic entry still works.
All existing Supabase configuration and approval permissions are unchanged.

WARNING: The translation model executes in the user's browser and requires
a reasonably capable device. No end-to-end live browser test performed.
